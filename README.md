## Resources

The following resources are useful for understanding the networking, HTTP, CGI, and testing concepts behind our 42 Webserv project:


(https://beej.us/guide/bgnet/) — TCP/IP fundamentals, sockets, and client-server communication.

(https://man7.org/linux/man-pages/man2/poll.2.html) — I/O readiness and event-driven server design.

(https://www.rfc-editor.org/rfc/rfc9112.html) — HTTP message syntax, parsing, and framing.

(https://www.rfc-editor.org/rfc/rfc3875.html) — CGI environment variables, request input, and program output.

(https://everything.curl.dev/) — Testing HTTP methods, requests, responses, and server behavior.

(https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Messages) - It was useful for me!
